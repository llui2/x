A language model receives text only after a tokenizer has converted it into a finite sequence of discrete symbols. If the tokenizer vocabulary contains $V$ symbols, an input of length $N$ is represented by
\begin{equation}
(u_1,\ldots,u_N),
\qquad
u_i\in\{1,\ldots,V\}.
\end{equation}
A token is therefore an element of the tokenizer vocabulary, not necessarily a complete word. Depending on the tokenizer, it can represent a word, part of a word, punctuation, whitespace, or another frequently occurring text fragment. The token identifier $u_i$ is only an integer label. The neural network first maps it to a vector. With embedding matrix $\mathbf E\in\mathbb R^{V\times d}$ and positional vector $\mathbf p_i\in\mathbb R^d$, the initial state of token $i$ is
\begin{equation}
\mathbf x_i^0
=
\mathbf E_{u_i}
+
\mathbf p_i.
\label{eq:embedding}
\end{equation}
The dimension $d$ is the model width. The collection $\mathbf x^\ell=(\mathbf x_1^\ell,\ldots,\mathbf x_N^\ell)$ will denote the token states after layer $\ell$. This is the first dynamical object: during a forward pass the parameters are fixed, while the token representations change with depth.

The basic interaction in a Transformer is self-attention \cite{vaswani2017}. For one attention head, each state is projected into a query, key, and value,
\begin{equation}
\mathbf q_i
=
\mathbf W_Q\mathbf x_i,
\qquad
\mathbf k_i
=
\mathbf W_K\mathbf x_i,
\qquad
\mathbf v_i
=
\mathbf W_V\mathbf x_i.
\label{eq:qkv}
\end{equation}
The query is the vector used by token $i$ to score other tokens, the key is the vector against which that query is compared, and the value is the information transmitted by the selected token. If the query and key dimension is $d_k$, the score from token $i$ to token $j$ is
\begin{equation}
s_{ij}
=
\frac{\mathbf q_i^{\mathsf T}\mathbf k_j}{\sqrt{d_k}}
+
m_{ij},
\label{eq:score}
\end{equation}
where $m_{ij}$ is a mask. In an autoregressive model, $m_{ij}=0$ for $j\leq i$ and $m_{ij}=-\infty$ for $j>i$, so token $i$ cannot use future tokens.

The scores are normalized with the softmax. For any vector $\mathbf z\in\mathbb R^m$,
\begin{equation}
\operatorname{softmax}(\mathbf z)_j
=
\frac{\exp(z_j)}{\sum_{r=1}^{m}\exp(z_r)}.
\label{eq:softmax}
\end{equation}
The output is a vector with nonnegative entries that sum to one, so it lies on the probability simplex
\begin{equation}
\Delta^{m-1}
=
\left\{
\mathbf a\in\mathbb R^m:
a_j\geq0,
\ \sum_j a_j=1
\right\}.
\end{equation}
For attention, the normalized coefficients are
\begin{equation}
a_{ij}
=
\frac{\exp(s_{ij})}{\sum_r\exp(s_{ir})},
\qquad
\mathbf y_i
=
\sum_j a_{ij}\mathbf v_j.
\label{eq:attention}
\end{equation}
Thus attention is a state-dependent interaction: the coefficients $a_{ij}$ are recomputed from the current token states rather than fixed in advance. A multi-head layer repeats the same calculation with several independent sets of query, key, and value matrices and then linearly combines the resulting outputs.

A Transformer block contains attention and a token-wise feed-forward network, both inserted through residual connections. Suppressing normalization and the distinction between the two residual substeps, the block can be written in the generic form
\begin{equation}
\mathbf x^{\ell+1}
=
\mathbf x^\ell
+
F_\ell(\mathbf x^\ell;\theta),
\label{eq:residual}
\end{equation}
where $\theta$ contains the trainable weights and $F_\ell$ contains the attention and feed-forward operations. The residual form is useful because it makes depth look like discrete time. Introducing a layer spacing $\Delta\tau$,
\begin{equation}
\mathbf x^{\ell+1}
=
\mathbf x^\ell
+
\Delta\tau\,
F(\mathbf x^\ell;\theta),
\end{equation}
and assuming that the sequence of layers approaches a sufficiently regular vector field as $\Delta\tau\to0$, one obtains
\begin{equation}
\partial_\tau\mathbf x_i
=
F_i(\mathbf x;\theta).
\label{eq:depth-flow}
\end{equation}
This is the continuous-depth viewpoint developed for residual and neural ODE models \cite{he2016resnet,chen2018neuralode}. The variable $\tau$ is depth. It should be kept distinct from the time associated with parameter learning.

For autoregressive language modeling, the final token state is projected back to the vocabulary. If $r_{ik}$ is the logit assigned at position $i$ to vocabulary token $k$, then
\begin{equation}
p_{ik}
=
\frac{\exp(r_{ik})}{\sum_{q=1}^{V}\exp(r_{iq})}
\end{equation}
is the predicted probability. If the observed next token is $y_i$, the cross-entropy contribution is $-\log p_{i y_i}$. Cross-entropy is the negative log-likelihood of the observed categorical outcome; minimizing it is therefore equivalent to maximizing the probability assigned to the training sequence under the model.

Training produces a second dynamics. Let $L(\theta)$ denote the loss averaged over the relevant data and let $B_n$ be the minibatch used at step $n$. Stochastic gradient descent gives
\begin{equation}
\theta_{n+1}
=
\theta_n
-
\eta\nabla_\theta L_{B_n}(\theta_n),
\label{eq:sgd}
\end{equation}
with learning rate $\eta$. In the small-step, full-batch approximation this becomes the gradient flow
\begin{equation}
\dot\theta
=
-\nabla_\theta L(\theta).
\label{eq:gradient-flow}
\end{equation}
The two evolutions are conceptually different: $\mathbf x$ changes with depth during inference, whereas $\theta$ changes across training steps. Practical optimizers such as AdamW add momentum, adaptive rescaling, and weight decay, so Eq.~\eqref{eq:gradient-flow} is a baseline continuous approximation rather than an exact representation of every training algorithm.

Several classical theories of deep learning can be placed around Eq.~\eqref{eq:gradient-flow}. Deep linear networks admit exact mode-by-mode learning dynamics and provide one of the cleanest solvable examples \cite{saxe2014}. In a different large-width limit, the neural tangent kernel freezes the feature map to leading order and turns training into approximately linear dynamics in function space \cite{jacot2018}. Mean-field limits retain feature evolution by replacing a large collection of trainable units with a probability distribution over parameters \cite{chizat2018}. If $\rho_t(\theta)$ denotes such a distribution, a typical Wasserstein gradient-flow form is
\begin{equation}
\partial_t\rho
=
\nabla_\theta\cdot
\left(
\rho\,
\nabla_\theta
\frac{\delta L}{\delta\rho}
\right).
\label{eq:parameter-pde}
\end{equation}
The functional derivative $\delta L/\delta\rho$ measures the first-order change in the loss produced by redistributing an infinitesimal amount of parameter mass. Equation~\eqref{eq:parameter-pde} is not another optimizer; it is a continuum description obtained after a mean-field limit.

Attention admits a parallel population description. For $N$ token states at depth $\tau$, define the empirical measure
\begin{equation}
\mu_\tau^N
=
\frac{1}{N}
\sum_{i=1}^{N}
\delta_{\mathbf x_i(\tau)},
\label{eq:token-measure}
\end{equation}
where $\delta_{\mathbf x}$ is a Dirac mass concentrated at $\mathbf x$. The measure $\mu_\tau^N$ records the distribution of token representations without retaining their labels. Under suitable mean-field assumptions, interacting-token models converge to transport equations of the form
\begin{equation}
\partial_\tau\mu
+
\nabla_{\mathbf x}\cdot
\left(
\mu\,\mathbf v[\mu]
\right)
=
0,
\label{eq:token-pde}
\end{equation}
where the velocity field $\mathbf v[\mu]$ is generated by the attention interaction. Recent work derives such descriptions for deep attention systems and studies their concentration, clustering, and long-depth behavior \cite{castin2025,rigollet2025}. A further mean-field construction couples the token distribution evolving through depth to a parameter distribution evolving through training \cite{herty2026}. This gives a natural common language for the two scales without identifying them: one distribution describes representations, the other describes trainable parameters.

A different but related line asks whether the forward dynamics is generated by an energy. If a vector field can be written as $\dot{\mathbf x}=-\nabla E(\mathbf x)$, then $E$ is a Lyapunov function and decreases along trajectories. Standard Transformers do not in general come with such a scalar energy. A precise connection exists for modern Hopfield networks, where an attention-like update follows from an associative-memory energy \cite{ramsauer2021}. For stored patterns $\boldsymbol\xi_1,\ldots,\boldsymbol\xi_M$, one convenient form is
\begin{equation}
E(\mathbf x)
=
\frac{1}{2}\mathbf x^{\mathsf T}\mathbf x
-
\frac{1}{\beta}
\log
\sum_{r=1}^{M}
\exp\left(
\beta\boldsymbol\xi_r^{\mathsf T}\mathbf x
\right),
\label{eq:hopfield-energy}
\end{equation}
up to terms independent of $\mathbf x$. Its stationary condition gives
\begin{equation}
\mathbf x
=
\sum_r
\frac{
\exp(\beta\boldsymbol\xi_r^{\mathsf T}\mathbf x)
}{
\sum_q\exp(\beta\boldsymbol\xi_q^{\mathsf T}\mathbf x)
}
\boldsymbol\xi_r,
\end{equation}
which has the same softmax-weighted retrieval structure as attention. Energy Transformer makes the energetic requirement explicit by modifying the architecture so that its recurrent update descends a constructed energy \cite{hoover2023}. The energy description is therefore a property to be established for a particular model, not a generic consequence of using attention.

Mixture-of-experts models introduce a new probability-valued object. Instead of applying one feed-forward network to every token, let $h_e(\mathbf x;\theta_e)$ be expert $e$, with $e=1,\ldots,K$. A router with parameters $\phi$ assigns scores
\begin{equation}
z_e(\mathbf x;\phi),
\qquad
e=1,\ldots,K,
\end{equation}
and converts them to allocation weights
\begin{equation}
a_e(\mathbf x)
=
\frac{\exp(z_e)}{\sum_{f=1}^{K}\exp(z_f)}.
\label{eq:router-softmax}
\end{equation}
A dense mixture returns
\begin{equation}
\mathbf y
=
\sum_{e=1}^{K}
a_e(\mathbf x)
\,h_e(\mathbf x;\theta_e).
\label{eq:dense-moe}
\end{equation}
Sparse MoE models evaluate only the experts with the largest router scores \cite{shazeer2017,fedus2022}. If $S(\mathbf x)$ is the set of the top $k$ experts, the selected weights are usually renormalized on $S(\mathbf x)$. Expert-choice routing changes the assignment rule by letting experts select tokens subject to capacity constraints \cite{zhou2022}. These implementation choices matter dynamically. Dense softmax routing is smooth, whereas top-$k$ routing is only smooth while the active set is unchanged; score crossings create switching events.

The allocation vector $\mathbf a=(a_1,\ldots,a_K)$ lives on the same probability simplex that appears in evolutionary dynamics. The connection can be stated exactly before giving it any biological interpretation. Let
\begin{equation}
a_e
=
\frac{\exp(z_e)}{\sum_f\exp(z_f)}.
\end{equation}
Differentiating with respect to time gives
\begin{equation}
\dot a_e
=
a_e
\left(
\dot z_e
-
\sum_f a_f\dot z_f
\right).
\label{eq:softmax-dynamics}
\end{equation}
If
\begin{equation}
f_e
=
\dot z_e,
\qquad
\bar f
=
\sum_f a_f f_f,
\end{equation}
then Eq.~\eqref{eq:softmax-dynamics} becomes
\begin{equation}
\dot a_e
=
a_e(f_e-\bar f),
\label{eq:replicator}
\end{equation}
which is the replicator equation introduced for frequency-dependent evolutionary selection \cite{taylor1978}. The equality is algebraic: every differentiable softmax trajectory has this form if $f_e$ is defined as the score velocity. Calling $f_e$ a fitness or payoff requires an additional statement about what generates the scores.

The geometry behind Eq.~\eqref{eq:replicator} is also standard. A tangent vector $\mathbf u$ to the interior of the simplex satisfies $\sum_e u_e=0$. The Fisher--Shahshahani metric is
\begin{equation}
g_{\mathbf a}(\mathbf u,\mathbf v)
=
\sum_e
\frac{u_e v_e}{a_e}.
\label{eq:shahshahani}
\end{equation}
For a categorical distribution with probabilities $a_e$, this is exactly the Fisher information metric \cite{harper2009}. The Fisher metric measures local distinguishability between nearby probability distributions. In optimization, using its inverse to convert an ordinary derivative into a direction of motion gives the natural gradient \cite{amari1998}. The softmax Jacobian
\begin{equation}
\mathbf M(\mathbf a)
=
\operatorname{diag}(\mathbf a)
-
\mathbf a\mathbf a^{\mathsf T}
\label{eq:mobility}
\end{equation}
is the corresponding inverse metric on the tangent space. Hence, if $f_e=\partial\Phi/\partial a_e$ for a scalar potential $\Phi(\mathbf a)$, Eq.~\eqref{eq:replicator} is natural-gradient ascent of $\Phi$. A general replicator field need not have such a potential.

The discrete learning counterpart is exponential weighting. If the scores are accumulated according to
\begin{equation}
z_e^{n+1}
=
z_e^n
+
\eta f_e^n,
\end{equation}
then softmax gives
\begin{equation}
a_e^{n+1}
=
\frac{
a_e^n\exp(\eta f_e^n)
}{
\sum_f a_f^n\exp(\eta f_f^n)
}.
\label{eq:exponential-learning}
\end{equation}
This is the multiplicative or exponential-weights update. Its continuous-time limit is the replicator equation, a standard result in reinforcement learning and learning in games \cite{mertikopoulos2016}. Coupled replicator equations have also been derived directly from interacting reinforcement-learning agents \cite{sato2003}. This provides a precise route from learning rules to evolutionary dynamics; it is stronger than a qualitative analogy between experts and species.

A neural router introduces an additional coupling because the scores are functions of both the representation and shared router parameters. For token $i$,
\begin{equation}
z_{ie}
=
z_e(\mathbf x_i;\phi),
\end{equation}
so
\begin{equation}
\dot z_{ie}
=
\nabla_{\mathbf x}z_e\cdot\dot{\mathbf x}_i
+
\nabla_\phi z_{ie}\cdot\dot\phi.
\label{eq:score-velocity}
\end{equation}
If the representation is held fixed while the router follows gradient flow, $\dot\phi=-\nabla_\phi L$, then
\begin{equation}
\dot z_{ie}
=
-
\sum_{j,f}
K_{ie,jf}
\frac{\partial L}{\partial z_{jf}},
\qquad
K_{ie,jf}
=
\nabla_\phi z_{ie}^{\mathsf T}
\nabla_\phi z_{jf}.
\label{eq:router-kernel}
\end{equation}
The matrix $K$ measures how changing the shared router parameters changes two logits together. It plays a role analogous to a tangent kernel for the router. The effective field $f_{ie}=\dot z_{ie}$ in Eq.~\eqref{eq:replicator} is therefore generally coupled across tokens and experts. Ordinary Euclidean gradient descent on a router is not equivalent to assigning every expert an independent fitness.

The same distinction is visible directly in the dense MoE loss. Let
\begin{equation}
\mathbf y_i
=
\sum_e a_{ie}\mathbf h_{ie},
\qquad
\mathbf h_{ie}
=
h_e(\mathbf x_i;\theta_e),
\end{equation}
and let $\mathbf g_i=\nabla_{\mathbf y_i}L$. Define
\begin{equation}
c_{ie}
=
\mathbf g_i^{\mathsf T}\mathbf h_{ie}.
\end{equation}
The quantity $c_{ie}$ is the first-order sensitivity of the loss to increasing the contribution of expert $e$ while keeping its output fixed. Differentiating through the softmax gives
\begin{equation}
\frac{\partial L}{\partial z_{ie}}
=
a_{ie}
\left(
c_{ie}
-
\sum_f a_{if}c_{if}
\right).
\label{eq:router-gradient}
\end{equation}
This centered relative-performance form resembles a replicator term, but the distinction is important. Euclidean gradient descent on the logits sets $\dot z=-\nabla_zL$ and then Eq.~\eqref{eq:softmax-dynamics} applies the softmax mobility once again. The standard replicator equation follows directly from score accumulation or from a natural-gradient dynamics on the simplex; it does not follow from every parameterization of router gradient descent.

The allocation variables also make specialization measurable without assigning semantic labels to experts. Let $\xi$ denote a random token together with the context that determines its router state, and let $J\in\{1,\ldots,K\}$ be the random expert selected with conditional probability $a_e(\xi)$. The mean expert load is
\begin{equation}
q_e
=
\mathbb E_\xi[a_e(\xi)].
\end{equation}
The entropy of the marginal expert distribution is
\begin{equation}
H(J)
=
-
\sum_e q_e\log q_e,
\end{equation}
while the conditional entropy is
\begin{equation}
H(J\mid\xi)
=
\mathbb E_\xi
\left[
-
\sum_e a_e(\xi)\log a_e(\xi)
\right].
\end{equation}
Entropy measures uncertainty: with natural logarithms it is measured in nats, and with base-two logarithms it is measured in bits \cite{shannon1948}. The mutual information
\begin{equation}
I(\xi;J)
=
H(J)-H(J\mid\xi)
\label{eq:mutual-information}
\end{equation}
measures how much knowing the token and its context reduces uncertainty about which expert is selected. It therefore measures input-dependent specialization. In contrast,
\begin{equation}
C
=
\log K-H(J)
\end{equation}
measures global load collapse relative to a perfectly balanced expert population. Uniform soft routing has $C=0$ and $I=0$; balanced deterministic routing has $C=0$ and large mutual information; complete routing collapse has large $C$ and zero mutual information. This separation is useful because current MoE work finds that routing structure need not correspond to one broad semantic domain per expert \cite{wang2026,lasy2026}.

The resulting common picture has three coupled levels. The representation state $\mathbf x$ evolves through depth according to a state-dependent interaction. The trainable parameters $(\theta,\phi)$ evolve through optimization. The allocation $\mathbf a$ is a probability-valued function of the representation and router parameters, and its induced motion is constrained by simplex geometry. In suitable large-system limits, $\mathbf x$ and $\theta$ can be replaced by distributions such as $\mu$ and $\rho$; in special architectures, the state dynamics can be generated by an energy; and for suitable score-learning rules, the allocation dynamics reduces to a replicator equation. These are different reductions of the same finite computational system rather than competing descriptions.

Their fixed points must also be distinguished. A state fixed point satisfies
\begin{equation}
F_i(\mathbf x^*;\theta,\phi)=0,
\end{equation}
a stationary point of gradient training satisfies
\begin{equation}
\nabla_\theta L=0,
\qquad
\nabla_\phi L=0,
\end{equation}
and an interior fixed point of Eq.~\eqref{eq:replicator} satisfies
\begin{equation}
a_e^*>0
\quad\Longrightarrow\quad
f_e^*=\bar f^*.
\end{equation}
The last condition states that every active component has the same effective score growth rate. In an evolutionary model this becomes the equal-fitness condition on the surviving types. In a neural router, the field $f$ must first be derived from the representation and optimization dynamics. Current theory already shows that router and expert feature learning can be coupled \cite{liao2026}; the mean-field Transformer literature likewise shows that representation and parameter distributions can be coupled across their two time variables \cite{herty2026}.

This identifies the main open theoretical step without requiring a new analogy. Starting from the actual finite gradient equations, one can ask when the score field in Eq.~\eqref{eq:score-velocity} closes approximately in terms of coarse allocation variables, when the resulting simplex dynamics has a potential, and when symmetric expert states lose stability. If such reductions exist, specialization, coexistence, exclusion, collapse, and switching can be studied with the fixed-point and bifurcation tools of dynamical systems and evolutionary theory. The role of the common language is to keep the assumptions behind each reduction explicit while allowing these results to be compared in the same notation.
